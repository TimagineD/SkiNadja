# AURA Visual QA

Visual QA is mandatory for UI work.

## Pass 1 — Structure

Check:
- container width
- grid
- alignment axes
- section spacing
- card geometry
- responsive breakpoints

## Pass 2 — Typography

Check:
- heading hierarchy
- line height
- weight
- line wrapping
- text density
- contrast

## Pass 3 — Components

Check:
- repeated components are identical
- icon sizes match
- radii match
- buttons have consistent height
- inputs align
- card padding is consistent

## Pass 4 — Visual hierarchy

Check:
- primary action is obvious
- secondary content is quieter
- whitespace is intentional
- gradients are restrained
- shadows communicate depth
- no unnecessary borders exist

## Pass 5 — Responsive

Inspect:
- desktop
- tablet
- mobile

Look for:
- clipped images
- horizontal overflow
- awkward wrapping
- oversized headings
- excessive vertical spacing
- controls becoming too small
- broken alignment

## Pass 6 — Interaction

Test:
- hover
- pressed
- keyboard focus
- disabled
- loading
- menus
- modals
- forms

## Pass 7 — Accessibility

Check:
- semantic elements
- labels
- keyboard navigation
- focus visibility
- contrast
- reduced motion

## Final rule

Do not declare the UI finished simply because the application runs.

AURA requires functional correctness AND visual correctness.
